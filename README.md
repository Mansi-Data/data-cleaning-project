# Data Cleaning Project - Netflix Dataset

## Dataset

Netflix Movies and TV Shows dataset from Kaggle.

## Issues Identified

* Missing values in director, cast, country
* Duplicate records
* Incorrect data types in date_added and release_year
* Inconsistent values (USA vs United States)

## Cleaning Steps

* Filled missing values with "Unknown" and "Not Available"
* Removed duplicate records
* Fixed date format
* Standardized country names
* Removed extra spaces

## Tools Used

* Microsoft Excel

## Files

* netflix_titles_raw.xlsx
* netflix_titles_cleaned.xlsx
